## Extraction Rules
1. Carefully scan the provided syllabus text, PDF, or image.
2. Identify EVERY graded item: assignments, pop quizzes, problem sets, labs, essays, midterms, and final exams.
3. For each item determine:
   - Name of the item
   - Type (exam, assignment, lab, quiz, paper)
   - Due date (in YYYY-MM-DD format if known, or original text if unclear)
   - Weight (% of total course grade)
4. Output the results in a clear Markdown table:
   | Item | Type | Due Date | Weight (%) |
